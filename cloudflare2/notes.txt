=====================================================================================================================================
CARA DEDAHKAN SERVIS PRIVATE KE INTERNET GUNA CLOUDFLARE TUNNEL
=====================================================================================================================================

1. CIPTA CLOUDFLARE TUNNEL

	- [BUKA ZERO TRUST] - CLOUDFLARE DASHBOARD > ZERO TRUST > KALI PERTAMA: NAMA TEAM + PLAN FREE
	- [CARI MANAGE TUNNELS] - NETWORK > OVERVIEW > MANAGE TUNNELS > CREATE A TUNNEL > CLOUDFLARE
	- [NAMA + OS] - NAMA: DEVOP-CLOUDFLARE2 > OS: DEBIAN | 64-BIT > SAVE
	
2. PASANG CONNECTOR
	- RUN COMMAND DI TERMINAL:
=====================================================================================================================================
PUB=$(aws ec2 describe-subnets --filters "Name=tag:Name,Values=*public*" --query "Subnets[0].SubnetId" --output text)
PRIV=$(aws ec2 describe-subnets --filters "Name=tag:Name,Values=*private*" --query "Subnets[0].SubnetId" --output text)
RTB=$(aws ec2 describe-route-tables --filters "Name=association.subnet-id,Values=$PRIV" --query \
"RouteTables[0].RouteTableId" --output text)
SG=$(aws ec2 describe-security-groups --filters "Name=group-name,Values=devops-sg" --query "SecurityGroups[0].GroupId" \
--output text)
EIP=$(aws ec2 allocate-address --domain vpc --query AllocationId --output text)
NAT=$(aws ec2 create-nat-gateway --subnet-id $PUB --allocation-id $EIP --query NatGateway.NatGatewayId --output text)
aws ec2 wait nat-gateway-available --nat-gateway-ids $NAT
aws ec2 create-route --route-table-id $RTB --destination-cidr-block 0.0.0.0/0 --nat-gateway-id $NAT
AMI="resolve:ssm:/aws/service/canonical/ubuntu/server/24.04/stable/current/amd64/hvm/ebs-gp3/ami-id"
aws ec2 run-instances --image-id $AMI --instance-type t3.micro --subnet-id $PRIV --security-group-ids $SG \
--iam-instance-profile Name=EC2-SSM-Role --no-associate-public-ip-address
=======================================================================================================================================
3. PERGI KE EC2 YANG DAH DICIPTA > SSM > PASANG NGINX & CLOUDFLARE > PERGI SEMULA KE CLOUDFLARE CONNECTOR > SALIN ARAHAN DAN TAMPAL DI SSM
